# INGEPRO RP V7.64 — Gestión de empresas y contactos
- Edición de empresas con validación de RUT y duplicados.
- Desactivación/reactivación administrativa de empresas (sin borrado físico).
- Edición de contactos, reasignación a empresa activa y conservación de cuatro funciones.
- Desactivación/reactivación de contactos por administrador.
- Formularios compactos dentro de ficha, sin cambios en el esquema PostgreSQL.
- Se conservan módulos existentes.
- Contactos no equivalen a cuentas de acceso al sistema.
