# INGEPRO RP V7.58

Se conserva la posición horizontal y vertical de la carta Gantt, la posición de la página y las OT expandidas después de guardar o liberar una asignación. El estado temporal se guarda únicamente en sessionStorage del navegador de la tablet. No se cambian permisos ni base de datos.

Prueba: desde supervisor, desplazarse a una OT inferior, crear asignación, guardar y comprobar que permanece en la misma zona.
