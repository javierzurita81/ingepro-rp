# INGEPRO RP V7.4 — Maestro de Reparaciones + Planificación

Base: V7.3 OT Despiece/Edición.

## Incorporado
- Maestro de reparaciones por componente de equipo.
- Reparación: nombre, descripción, proceso, HH estimadas, recurso/especialidad, máquina y secuencia.
- Módulo Planificación mensual inspirado en la planilla de programación INGEPRO.
- Solo OT con cotización aprobada aparecen para planificación.
- Selección OT -> componente -> reparación maestra.
- Asignación libre de cualquier trabajador activo a cualquier tarea/equipo.
- Fechas inicio/término, horas/día, estado y observación.
- Grilla mensual de actividades y carga diaria por trabajador.
- Advertencia visual de sobrecarga cuando un trabajador supera 8 h/día.
- Usuario: RUT, correo, sigla y color de planificación.
- Sigla y color no repetibles entre usuarios.
- Modificación de usuarios existente.
- Permiso específico de Planificación.

## Nota
Los usuarios Administrador reciben acceso a Planificación automáticamente. Para usuarios normales, activar el permiso Planificación desde Usuarios.
