# INGEPRO RP V7.25 — Estado visual de etapas

Basada en V7.24. En la planificación Gantt compacta, el selector desplegable Aplica/N/A se reemplazó por un botón de texto verde **Aplica** y rojo **No aplica**. Un clic alterna el estado usando el mismo endpoint de V7.24. Las etapas con horas asignadas mantienen la protección contra marcar No aplica sin desprogramarlas antes. Sin migraciones de base de datos. Se conserva el resto del módulo, incluidos PDFs y editor rápido.
