# INGEPRO RP V7.2 — Diagnóstico Técnico

Actualización acumulativa sobre V7.1. Conserva clientes, usuarios, equipos, OT y cotizaciones.

Nuevo módulo por OT: Inspección y Diagnóstico Técnico.
- Hallazgos por componente.
- Foto desde tablet/teléfono o archivo.
- Zona, condición encontrada, trabajo recomendado, observación y estado.
- Fotografías comprimidas y guardadas en PostgreSQL para que no dependan del disco temporal de Render.
- Informe PDF corporativo INGEPRO División Maestranza.
- Auditoría de creación/eliminación y generación del PDF.

La estructura principal de OT se mantiene para revisión posterior.
