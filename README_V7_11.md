# INGEPRO RP V7.11 — Reparaciones y responsables

- Planificación lista TODAS las reparaciones activas del maestro para cada componente recibido de la OT. Las que no están seleccionadas en Diagnóstico aparecen como pendientes y no pueden programarse hasta seleccionarlas.
- Enlace al diagnóstico para marcar trabajos; mantiene la regla de trazabilidad.
- Administración puede habilitar usuarios internos activos como operarios desde Planificación; los contactos de clientes siguen excluidos.
- Mantiene OT aprobadas, colores, siglas, alarmas, edición y eliminación.
- No modifica registros existentes ni cambia el esquema de base de datos.

**Prueba:** primero vincular el componente de la OT con el maestro correcto, luego seleccionar reparaciones en Diagnóstico. Habilitar operarios desde Planificación si la lista está vacía.
