# INGEPRO RP V7.5 — Edición de planificación

Base: ZIP V7.4 proporcionado por el usuario.

- Botón Editar por actividad: trabajador, tarea, fechas, horas diarias, estado y observaciones.
- Asignación de un segundo o más responsables a una tarea (cada asignación independiente con sus propias horas).
- Colores y siglas por usuario, leyenda permanente en planificación.
- Control de sobrecarga diaria existente se conserva.
- Se conservan módulos y despliegue Render existentes.

Subir el ZIP a GitHub/Render según el flujo de despliegue habitual.
