# INGEPRO RP V7.9 – Corrección filtro de OT aprobadas

Se corrigió el listado de OT disponibles para planificación: ahora considera la aprobación en la cotización activa o en la OT, y no incluye cotizaciones anuladas o expresamente rechazadas. Se mantienen los filtros de componentes recibidos, reparaciones seleccionadas y trabajadores operativos.

**Pruebas recomendadas:** aprobar dos o más cotizaciones de distintas OT, abrir Planificación y comprobar que todas aparecen. Comprobar que una cotización rechazada o anulada no aparece.

No se modifican bases de datos ni se incluyen migraciones. Probar primero en entorno de pruebas.
